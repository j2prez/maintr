# Maintr

> What you own says a lot. How you maintain it says more.

Fleet, bike, and home maintenance tracker — powered by Supabase.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Deploy

Push to GitHub, then connect repo to [Vercel](https://vercel.com).
Vercel auto-detects Vite and deploys on every push.

## Tech
- React 18 + Vite
- Supabase (Postgres + Storage + Auth)
- PWA ready
